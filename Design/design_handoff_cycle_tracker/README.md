# Handoff: Трекер женского цикла

## Overview
Мобильное приложение для отслеживания менструального цикла. Минималистичный интерфейс: главный экран со светящимся круглым индикатором цикла, календарь с фактами/прогнозом менструаций, экран профиля с настройками.

## About the Design Files
Файлы в этом пакете — **дизайн-референсы, сделанные в HTML** (интерактивные прототипы поведения и внешнего вида), а не production-код для копирования. Задача разработчика — **воссоздать эти экраны в целевом окружении проекта** (React Native / Flutter / SwiftUI / Android native — выбрать то, что уже используется в кодовой базе, либо, если стека ещё нет, наиболее подходящий фреймворк для мобильного приложения) с использованием его нативных паттернов, а не встраивать HTML как есть.

## Fidelity
**High-fidelity.** Цвета, типографика, отступы и интеракции — финальные значения, разработчик должен воссоздать UI пиксель-в-пиксель средствами нативного стека.

## Screens / Views

### 1. Главный экран ("Сегодня")
**Purpose:** показать текущий день цикла и позволить зафиксировать начало/окончание месячных.

**Layout:** вертикальный flex-контейнер, по центру. Отступы 28px сверху/по бокам, 24px по бокам. Круг 272×272px с отступом 18px от верха.

**Components:**
- **Кольцо цикла** — круг, залитый по часовой стрелке cSS conic-gradient: прошедшие дни — акцентный цвет, оставшиеся — приглушённый (тёмный/светлый в зависимости от темы). Рассчитывается как `(currentDay/cycleLength)*360deg`. Внутри — второй SVG-круг (`stroke-dasharray`, `pathLength="360"`) показывает сегмент менструации (первые N дней цикла) короткими штрихами (5 линий, как тактильные насечки циферблата) поверх кольца. Вокруг кольца — блюр-подсветка (glow), в тёмной теме анимированная (переливающееся свечение, keyframes `hue-rotate` 6s loop).
- **Число в центре круга** — только цифры, крупный шрифт (64px) `текущий_день/длина_цикла`, никакого текста.
- **Кнопка UNDO** — 48px круг слева от главной кнопки, всегда видна, приглушённая (opacity 0.35) когда нечего отменять, полная яркость когда есть последнее действие для отмены. Иконка — стрелка возврата.
- **Главная кнопка действия** (76px круг):
  - Если месячные не идут: капля (droplet icon), акцентный цвет — "начались месячные". Долгое нажатие (450ms) открывает веер из 2 доп. кнопок слева ("-1" вчера, "-2" позавчера) для фиксации начала задним числом. Отпускание пальца без движения — меню остаётся открытым для выбора; клик в любое место экрана — закрывает.
  - Если месячные идут: квадрат в рамке — "закончились месячные", фиксирует фактическую длину как `currentDay`.
- **Нижняя навигация** — 2 иконки-таба (круг "сегодня", силуэт человека "профиль"), без текста.
- **Свайп вправо** с главного экрана → открывает экран календаря.

### 2. Календарь
**Purpose:** обзор факта/прогноза менструаций по месяцам, ручная корректировка отдельных дат.

**Layout:** тот же вертикальный контейнер, отступы 28px/20px. Заголовок месяца с стрелками навигации по бокам (36px круглые кнопки). Сетка 7×N дней (grid, 7 колонок), подписи дней недели сверху.

**Components:**
- **Заголовок месяца** — `<месяц> <год>` (локаль ru-RU), стрелки prev/next.
- **Навигация по месяцам** — свайп влево (будущее)/вправо (прошлое) в любом месте сетки, либо клик по стрелкам. Порог свайпа — 60px по X, не более 40px по Y.
- **Ячейка дня** (34px круг): 
  - Факт менструации (прошедшая дата, попадает в расчётный диапазон менструации, либо вручную подтверждена) — сплошная заливка акцентным цветом, белый/тёмный текст.
  - Прогноз (будущая дата в расчётном диапазоне) — пунктирная (dashed) обводка акцентным цветом.
  - Сегодня — дополнительное кольцо-аутлайн (box-shadow 2px) акцентным цветом.
  - Обычный день — прозрачный фон, цвет текста = основной "ink".
- **Тап по дате** — открывает круглую кнопку (52px) ПРЯМО НА этой дате (перекрывая её, `transform: translate(-50%,-50%)` от координат нажатой ячейки):
  - Если дата зафиксирована как факт — крестик (удалить отметку).
  - Если дата не зафиксирована — плюс (добавить отметку месячных).
  - Клик в любое другое место экрана закрывает меню без изменений.
- **Легенда** внизу — два пункта: сплошная точка "Факт", пунктирная точка "Прогноз".

**Логика расчёта дня цикла:** `cycleStartDate = сегодня - (currentDay - 1) дней`. Для произвольной даты: `diffDays = date - cycleStartDate` (в днях), `cyclePos = diffDays mod cycleLength` (положительный остаток), `isPeriodDay = cyclePos < periodLength`. Ручные правки хранятся отдельно как overrides по дате (`{ "2026-09-28": true/false }`) и имеют приоритет над расчётом.

### 3. Профиль
**Purpose:** настройки персональных параметров цикла.

**Layout:** вертикальный список карточек-групп (border-radius 18px, разделители 1px между строками внутри группы), заголовок "Профиль" 28px сверху.

**Components (группа 1 — личные данные):**
- **Дата рождения** — `<input type="date">`, обычный системный пикер.
- **Год начала менструаций** — степпер (–/+ круглые кнопки 30px, число посередине).

**Components (группа 2 — параметры цикла):**
- **Длительность цикла** — степпер, диапазон 15–45 дней.
- **Длительность менструации** — степпер, диапазон 1–12 дней.

**Components (группа 3 — уведомления):**
- **Напоминания** — тумблер (48×28px pill), акцентный цвет когда включён.

**Нижняя навигация** — та же, что на главном экране.

## Interactions & Behavior
- **Начало цикла**: сброс `currentDay=1`, `isPeriodActive=true`, сохраняет предыдущее состояние в `history` для undo.
- **Окончание месячных**: фиксирует `periodLength = currentDay` (реальная длительность может отличаться от настроенной), `isPeriodActive=false`.
- **Undo**: восстанавливает `history` (один шаг назад), затем очищает историю.
- **Долгое нажатие** (450ms threshold) на кнопку "начались месячные" → веер из 2 кнопок ("-1"/"-2" дня) слева от кнопки, для фиксации задним числом. Закрывается кликом вне зоны или выбором опции.
- **Свайп вправо** на главном экране (dx > 60px, |dy| < 40px) → переход на календарь.
- **Свайп влево/вправо** в календаре → месяц вперёд/назад.
- **Тема**: light/dark — задаётся тумблером (в макете реализовано как prop/tweak). Тёмная тема: фон с цветным отливом (не чёрный), кольцо — многоцветное переливающееся свечение с анимацией.
- **Палитра**: 4 варианта акцентного цвета (warm/lavender/sage/dusk) — глобально меняет hue всех акцентных элементов через `oklch()`.

## State Management
Ключевые поля состояния:
- `screen`: 'today' | 'calendar' | 'profile'
- `cycleLength`, `periodLength`, `currentDay`: number
- `isPeriodActive`: boolean
- `history`: снапшот для undo (или null)
- `birthDate`: ISO date string
- `menarcheYear`: number
- `calendarMonthOffset`: number (0 = текущий месяц)
- `manualOverrides`: { [dateISO]: boolean } — ручные фиксации/удаления дат в календаре
- `selectedDate`, `selectedIsFact`, `selectedPos`: состояние открытого меню в календаре
- `remindersOn`: boolean

## Design Tokens
Все цвета строятся динамически в OKLCH от одного `hue` (h), заданного палитрой:
- warm: h=40 (акцент `oklch(0.72 0.15 25)`)
- lavender: h=300
- sage: h=145
- dusk: h=250

Светлая тема:
- bg: `oklch(0.975 0.012 h)`
- cardBg: `oklch(0.99 0.005 h)`
- chipBg: `oklch(0.94 0.01 h)`
- ink (основной текст): `oklch(0.3 0.02 h)`
- inkMuted: `oklch(0.62 0.02 h)`
- inkFaint: `oklch(0.7 0.02 h)`

Тёмная тема:
- bg: `oklch(0.17 0.045 h)` (с цветным отливом, не чистый чёрный)
- cardBg: `oklch(0.24 0.05 h)`
- ink: `oklch(0.94 0.01 h)`
- акцент — многоцветный conic-gradient (переливание), анимация `hue-rotate` 6s linear infinite

Шрифт: системный (`-apple-system, 'SF Pro Text', Helvetica, Arial, sans-serif`).
Радиусы: круглые элементы — `border-radius: 50%`; карточки — 16–18px; чипы/пилюли — 8–14px.
Размеры кнопок: главная круглая кнопка 76px, undo/навигация по месяцам 36–48px, попап-кнопки в календаре/веере 52–58px.
Минимальный размер кликабельной области — 30px (степперы), крупные действия — 76px.
